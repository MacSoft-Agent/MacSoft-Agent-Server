### Workflow note

The normal lifecycle is investigation, design review, implementation,
verification, independent review when required, integration, and status
recording. Small low-risk changes may use a lighter written record. Medium work
should use this template; high-risk work should use it and obtain explicit
owner decisions before crossing durable product boundaries.
