# Configuration Usage and Escalation

Read stable values from `pharmarise-company-configuration`; do not duplicate them here. Resolve company, canonical account book, archive location, fixed operational group, and default notification/escalation recipient.

Dynamic supplier contacts come from `whatsapp_identifiers`, not the Company Skill. Contact mapping does not grant accounting approval.

Ask instead of guessing when account book, archive destination, supplier contact, or operational channel is missing/ambiguous. Escalate unresolved supplier/PO decisions, unsupported AutoCount operations, repeated archival failures, or unavailable authorized approvers to the configured recipient. The default admin is a notification recipient, not automatically an approver.
