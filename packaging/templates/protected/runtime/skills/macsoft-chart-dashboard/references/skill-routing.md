# Skill routing

| User need | Required skill | Optional skill |
|---|---|---|
| One chart or comparison | `macsoft-chart-visualization` | `web-design-engineer` |
| Several charts or headline metrics | `kpi-dashboard-design` | `data-storytelling` |
| Explanation, finding, or recommendation | `data-storytelling` | `kpi-dashboard-design` |
| Polished HTML dashboard | `web-design-engineer` | `kpi-dashboard-design` |
| AutoCount-backed result | `macsoft-autocount:autocount-operations` | — |

Do not load every skill for every request. Load the smallest set that covers
the requested output, then read only the relevant reference files.
