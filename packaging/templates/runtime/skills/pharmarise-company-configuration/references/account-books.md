# Account books

Customer-owned values. Add one section per company and account book.

## Template

- `company_id`: `NOT_CONFIGURED`
- `account_book_id`: `NOT_CONFIGURED`
- Display name: `NOT_CONFIGURED`
- AutoCount Connector ID: `NOT_CONFIGURED`
- Active: `false`

The workflow must use `company_id` and `account_book_id` for isolation. The Connector ID is transport configuration and is not a substitute for either identity.
